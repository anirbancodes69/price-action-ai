# DECISIONS — Decision Register

Rules: accepted decisions are changed only through a superseding ADR (see [CLAUDE.md §8](CLAUDE.md#8-decision-change-protocol)). Add a row here whenever an ADR is added or its status changes. Statuses: `Accepted`, `Proposed`, `Superseded by …`, `Deprecated`.

| DEC-016 | Personal intraday workstation | 2026-11-17 | Accepted | Primary use is a single-user intraday price-action workstation: NSE cash, NIFTY 50, 15m structure + 5m setups, daily as context only, closed bars only, long-only actionability (C-12 kept), manual execution, account-level intraday risk limits, ruleset `pa-intraday`. SaaS features deferred, not removed. M2–M10 replaced by I0–I8. | Owner's actual use; cheapest moment to change direction (no engine/ingestion/API code yet) | [ADR-014](docs/adr/ADR-014-PERSONAL-INTRADAY-WORKSTATION.md) |
| DEC-017 | Intraday time model and snapshots by reference | 2026-11-17 | Accepted | Bars keyed by `bar_start timestamptz` (timeframes 1m/5m/15m/1D, only completed bars, provider-native 5m/15m); corrections kept in `candle_revisions`; snapshots reference a bar range plus content hash instead of copying a payload; runs link several inputs (5m, 15m, daily); timestamps on derived and trading rows. | Keeps C-08 reproducibility at intraday run volume | [ADR-015](docs/adr/ADR-015-INTRADAY-TIME-AND-SNAPSHOT-MODEL.md) |
| DEC-018 | Live engine proxy for the scanner and analysis | 2026-11-18 | Accepted | In personal mode Laravel serves `GET /scanner` and `GET /analysis/{symbol}` by calling the engine live (no persisted batches); persisted analysis (ARC-03 §7) is deferred, not removed. | DEC-019 | Trade plans without stored analysis runs | 2026-11-19 | Accepted | A plan may exist without an `analysis_run_id`: it records its own setup type, PAQS, bar time, engine levels, ruleset and risk profile. | DEC-020 | Independent strategy library | 2026-11-21 | Accepted | Twelve price-action strategies, in a fixed order, developed and validated one at a time. VWAP Pullback stays `DEFERRED` until the owner changes the methodology (TRD-01 MP-01 is unchanged). | The first backtests ran strategies together, so no result is attributable to one strategy; the adaptive engine needs per-strategy evidence | [ADR-018](docs/adr/ADR-018-INDEPENDENT-STRATEGY-LIBRARY.md) |
| DEC-021 | Daily-timeframe research track (longer holding period) | 2026-11-23 | Accepted | A research-only daily-bar, multi-day-hold track added to the ADR-018 process; the product scope stays intraday (ADR-014 not superseded). Gate 0 first: a framework diagnosis on daily data under delivery costs before any strategy. Friction at planning values is no lower than intraday until stops reach about 3% to 4% | Intraday evidence (diagnosis, fast screen) shows no entry edge over random entries at about 0.3R friction; the one lever left is friction relative to the stop | [ADR-019](docs/adr/ADR-019-DAILY-TIMEFRAME-RESEARCH-TRACK.md) |
